# 🚀 Portfolio de proyectos técnicos

En este repositorio organizo y documento laboratorios, prácticas y proyectos técnicos relacionados con infraestructura IT, administración de sistemas, redes, virtualización y ciberseguridad.

El objetivo de este portfolio es seguir desarrollando conocimientos prácticos en entornos similares a empresa y construir una base sólida orientada al ámbito profesional de la ciberseguridad e infraestructura.

---

# 🌐 Redes y Servicios

Proyectos relacionados con infraestructura de red, routing, virtualización y despliegue de servicios.

## Proyectos principales

### 🎬 Proyecto Cine Enterprise
Infraestructura de red empresarial simulada en Cisco Packet Tracer con VLANs, routing, OSPF, DHCP, DNS y segmentación de red.

### 🖥️ Proxmox LAB
Entorno de virtualización utilizando contenedores LXC, NAT, iptables y routing Linux.

### 🔐 pfSense + OpenVPN
Laboratorio orientado a firewalling, acceso remoto seguro y configuración de VPNs.

### 📡 NGINX RTMP Streaming
Servidor de streaming en tiempo real utilizando NGINX RTMP, OBS Studio y VLC.

### 📂 WebDAV + RAID5
Sistema de almacenamiento tolerante a fallos utilizando RAID5 y compartición de archivos mediante WebDAV.
